# Econ Cram — Chapters 9–11

A standalone study drill for production costs, pure competition, and monopoly. Open [index.html](./index.html) in a browser, or use the GitHub Pages copy of this repo (path `/econ-cram/`).

This is a static app, not a hosted account service. Scores are stored only in **this browser** on this device (no cloud sync). Use **Export backup** if you switch phones, browsers, or private mode.

On iPhone, open the page in Safari. A Files-app preview often will not run JavaScript. Reloading after an update replaces the question bank but does **not** wipe saved scores.

The fuller class log is incomplete in places (missing tables, graphs, and some exact prompts). The app labels answer-key recalls, conceptual substitutes, and supplemental drills, and it lists source gaps in Progress.
